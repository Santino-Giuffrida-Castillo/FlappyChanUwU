# FlappuChanUwU (v1.0)

Remaster estilo arcade de *Flappy Bird* desarrollado en **C++** utilizando la librería gráfica y multimedia **Raylib**. Incluye modo cooperativo local para 2 jugadores, fondo con efecto *parallax* multicapa, gestión de estados de pantalla y sistema de audio completo con música dinámica y efectos de sonido.



## Controles

### Navegación de Menús
| Tecla | Acción |
| :--- | :--- |
| **`1`** | Iniciar partida |
| **`2`** | Ver créditos |
| **`3`** | Abrir opciones |
| **`4`** | Ver tutorial |
| **`5`** | Salir del juego |
| **`J`** | Activar / Desactivar Jugador 2 (en pantalla *Options*) |
| **`R`** | Reintentar partida (en pantalla *Lose*) |
| **`ESC`** | Volver al menú principal |

### En Partida (`PLAY`)
| Jugador | Tecla | Acción |
| :--- | :--- | :--- |
| **Jugador 1** (Blanco) | **`W`** | Saltar / Impulsarse hacia arriba |
| **Jugador 2** (Rojo) | **`ESPACIO`** | Saltar / Impulsarse hacia arriba |
